# 🌤️ Weather App

A simple and responsive **Weather App** built using **HTML, CSS, and JavaScript**.
It uses the **OpenWeather API** to fetch and display real-time weather information for any city.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Current temperature in Celsius
* 🤚 Feels-like temperature
* 💧 Humidity
* 🌬️ Wind speed in km/h
* 👀 Visibility in km
* ☁️ Weather condition with dynamic icons
* 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* OpenWeather API

## ⚙️ How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter a city name in the search box.
4. Click the search button.
5. View the current weather information.
